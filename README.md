# KOU_C_PROJECTS
Kocaeli University ProLab 1 Assignment and C Applications
The logic of this project works like this: tasks are assigned to technicians based on the algorithm chosen by the user. The algorithm we developed ourselves is the most efficient. Here, the 1-unit transition penalty for technicians should not be forgotten. Also, a report of this program is included in the document file, and this project meets every requirement specified by the document. We tested this project using the tasks.txt file, and if you want, you can add to the file and test it yourself too.
